Operating Systems Principles Applied to Banking Architecture
Amdahl's Law in Transaction Engines

Speedup \(S(N) = \frac{1}{(1-P) + \frac{P}{N}}\)

In financial systems, sequential fractions \((1-P)\) arise from central ledger write locks. Minimizing lock holding times allows near-linear scaling up to hundreds of concurrent tellers.

I/O Concurrency vs CPU Parallelism

Network calls release CPU cores during external settlements.

When a teller thread calls external card networks or SWIFT gateways, it enters the BLOCKED state. Other tellers immediately process retail ATM transactions, achieving 6× throughput gains.

Banker's Resource Ordering Protocol

Circular dependency is eliminated mathematically.

By requiring all transfer threads to request account locks in ascending order of Account ID, the Coffman circular wait condition cannot form, guaranteeing zero transfer freezes.
