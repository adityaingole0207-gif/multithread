Operating Systems Theoretical Insights & Amdahl's Law
Amdahl's Law Formula

Speedup \(S(N) = \frac{1}{(1-P) + \frac{P}{N}}\)

\(P\) is the parallel fraction and \(N\) is the thread count. If 20% of work is sequential \((1-P = 0.2)\), the maximum theoretical speedup is strictly capped at 5x regardless of how many threads or CPU cores are added.

I/O-Bound Efficiency

Threads release CPU during I/O operations.

When a thread calls sleep, socket read, or disk seek, the OS scheduler moves it from RUNNING to BLOCKED. Another READY thread can immediately utilize the core, achieving near-linear multi-threaded speedups.

CPython Global Interpreter Lock (GIL)

Threads share memory; Processes share no memory.

CPython's GIL restricts pure bytecode execution to a single OS thread at a time. True multi-core CPU scaling for Python requires OS Multiprocessing, which spawns distinct processes each possessing an independent interpreter and memory space.
